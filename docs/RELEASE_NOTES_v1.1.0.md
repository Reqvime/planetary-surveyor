# Planetary Surveyor v1.1.0

Press F10 on a planet to discover its fauna. The optional All mode also tries
to discover flora and minerals. You do not need the analysis visor, a target or
an external launcher.

## Included

- Full-planet fauna discovery
- Optional flora and mineral discovery
- Normal Steam launch
- In-game settings for mode, hotkey, delay and sound
- Support for small game updates through runtime signature matching

Tested on No Man's Sky 7.0 for Windows with Steam executable versions 178994
and 179292.

Flora and mineral totals may remain incomplete on some planets. Back up your
save and prefer single-player or offline use.
