# Этап 4: read-only снимок scannable component pool

> Этот эксперимент только читает один bounded snapshot глобального пула
> `cGcScannableComponent`. Он не вызывает discovery submit, не меняет аргументы
> игровых функций и не должен изменять сохранение.

## Гипотеза

Специализированный `cTkComponentPoolInterfaceT<cGcScannableComponent>` содержит
живые компоненты загруженных сканируемых сущностей. Среди них должен найтись
компонент неизвестного минерала, на который наведён визор.

## Перед запуском

1. Игра должна быть полностью закрыта.
2. Использовать одиночный или офлайн-режим.
3. Оставить сторонний AutoScannerPlus отключённым.
4. Убедиться, что восстановлено нужное тестовое сохранение.

## Один контрольный запуск

```powershell
Set-Location -LiteralPath "C:\path\to\No Man's Sky\NMSDiscoveryLab"
.\scripts\deploy.ps1
.\scripts\run.ps1 -BackupConfirmed -PreflightOnly
.\scripts\run.ps1 -BackupConfirmed
```

После загрузки сохранения:

1. Открыть анализирующий визор.
2. Навести его на один неизвестный минерал и дождаться появления его карточки.
3. Не начинать обычное сканирование.
4. Не убирая прицел с минерала, один раз нажать и отпустить F8.
5. Подождать 3–5 секунд и штатно закрыть игру.

F8 визуально ничего не меняет — это ожидаемо. В логе должны появиться
`ScannablePoolSnapshotRequested`, `ScannablePoolSnapshotBegin` и
`ScannablePoolSnapshotEnd`. Главный результат — `target_matches` и число
`exact_components`.

Если игра вылетела или зависла, сразу сообщить об этом и не повторять запуск.
