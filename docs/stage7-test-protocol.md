# Этап 7: player-centred wide-radius submit

> Этот этап изменяет сохранение. Пользователь подтвердил резервную копию,
> разрешил mutation и отдельно согласился на длительный фриз ради большого
> радиуса.

## Гипотеза

Позиция `cGcPlayerEnvironment::mPlayerTM` может заменить цель визора как центр
scene-node снимка. F8 должен работать без открытия визора. Радиус теста — 1000
метров; resolver обрабатывает максимум 4096 ближайших живых узлов, а очередь
ограничена 64 уникальными неизвестными discovery.

Большой радиус не генерирует объекты всей планеты. Он охватывает только scene
nodes, которые уже загружены текущим процессом игры.

## Контрольный запуск

```powershell
Set-Location -LiteralPath "C:\path\to\No Man's Sky\NMSDiscoveryLab"
.\scripts\deploy.ps1
.\scripts\run.ps1 -BackupConfirmed -PreflightOnly
.\scripts\run.ps1 -BackupConfirmed
```

После загрузки сохранения:

1. Находиться пешком на нужной планете в одиночном/offline режиме.
2. Не открывать визор и не наводиться на объект.
3. Записать исходные счётчики Animal, Flora и Mineral.
4. Один раз нажать и отпустить F8.
5. Не нажимать клавиши во время возможного фриза. После возврата управления
   подождать до 90 секунд: открытия отправляются по одному в секунду.
6. Записать новые счётчики, но игру не закрывать.

Успешный лог содержит `center_source=player`, конечную позицию игрока,
`radius_metres=1000.0`, `NearbyDiscoverySubmitQueueReady` и
`NearbyDiscoverySubmitEnd`. Визорная `PopulateDiscoveryInfo` до F8 для успеха
не требуется.

Если управление не вернулось за 60 секунд, игра вылетела или появились явно
неверные открытия, не повторять F8 и сообщить результат до закрытия процесса.
