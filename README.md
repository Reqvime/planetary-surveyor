# Planetary Surveyor

Planetary Surveyor discovers the fauna on your current planet with one key
press. It can also try to discover the planet's flora and minerals.

Fauna is the reliable part. Flora and minerals are still experimental and may
miss a few entries on some planets.

## Install

1. Back up your save and close the game.
2. Download `Planetary-Surveyor-v1.1.1.zip` from the Releases page. Do not use
   GitHub's automatic `Source code` downloads; they are for developers.
3. Extract the archive into the main No Man's Sky folder.
4. If `Binaries\version.dll` already exists, keep it.
5. If it does not exist, copy the included optional `version.dll` into
   `Binaries`.
6. Start the game normally through Steam.

There is no installer, console window or separate Python setup. Python is
already included in the archive.

## Use

Stand on a planet and press F10. Keep the game focused until the sounds stop.
Pressing the key again while a scan is running does nothing.

The settings are in the Planetary Surveyor section of the Options menu:

- Fauna Only or All
- F1 to F12 scan key
- 250 to 1500 ms delay
- sound on or off
- scanner enabled or disabled

The default setup is F10, Fauna Only, 500 ms and sound enabled. A new scan key
takes effect after restarting the game. Other settings apply immediately.

## Notes

- Back up your save. Discoveries cannot be undone one by one.
- Single-player or Steam Offline Mode is recommended.
- Flora and mineral totals do not always match the catalogue generated by the
  game, so full completion is not guaranteed yet.
- Epic Games has not been tested.
- The mod was tested on Steam executable versions 178994 and 179292.

Logs are stored in `PlanetaryDiscoveryScanner\logs`.

Do not copy `app` or `runtime` into `GAMEDATA`. If the settings appear but F10
does nothing, close the game and include the newest log files when reporting
the problem.

## How it works

The mod reads the catalogue already generated for the current planet. Unknown
entries are passed to the game's own discovery functions. It does not use an
online database and does not modify `NMS.exe`.

This is a runtime mod rather than a `.pak`, which is why the release includes a
small native loader and an embedded Python runtime.
