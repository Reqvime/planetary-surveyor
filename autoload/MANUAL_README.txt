PLANETARY SURVEYOR 1.1.1
========================

INSTALL

1. Close No Man's Sky and back up your save.
2. Extract everything into the main No Man's Sky folder.
3. Open the Binaries folder.
4. If version.dll already exists, leave it alone.
5. If version.dll is missing, copy the included optional version.dll into
   Binaries.
6. Start the game normally through Steam or Epic Games.

USE

Stand on a planet and press F10 once. Keep the game focused until the scan
finishes. Settings are available in Options under Planetary Surveyor.

Fauna scanning is reliable. Flora and mineral scanning is optional and may miss
some entries.

Do not move app or runtime into GAMEDATA. If the settings appear but F10 does
nothing, close the game and check PlanetaryDiscoveryScanner\logs.

UNINSTALL

Delete Binaries\PlanetaryDiscoveryScanner.mods,
Binaries\PlanetaryDiscoveryScanner.ini, and the PlanetaryDiscoveryScanner
folder. Delete Binaries\version.dll only if you installed the included copy and
no other native mod uses it.
